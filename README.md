# Хоккейный класс

Автономное HTML-приложение с хоккейными тестами и словарём для детей.

## Запуск

Откройте `index.html` двойным кликом — сервер и сборка не нужны.

Для локальной разработки также можно запустить из папки проекта:

```bash
npx vite hockey
```

## Тесты

Тесты по правилам собираются из банка `window.HOCKEY_RULES` в `rules-01.js`.
Каждый вопрос привязан к правилу и странице книги. Тесты группируются по разделам
и отдельным правилам.

Квизы по словарю генерируются автоматически из `terms.js`; варианты ответов
подбирает модуль `distractors.js`. Во время теста можно вернуться к предыдущему вопросу,
но изменить уже выбранный ответ нельзя. Незаконченный тест сохраняется, его можно
продолжить с главной страницы. Для тестов правил после результата доступна кнопка
«Переиграть ошибки». Для каждого теста хранится и показывается количество попыток.
Результаты и рекорды сохраняются в `localStorage` браузера.

## Хоккейный словарь

В `terms.js` находится 107 терминов. Совпадающие термины объединяются
в 106 учебных карточек через поля `aliases` и `aliasOf`. Для каждой карточки указаны:

- английское и русское названия;
- короткое объяснение;
- тематическая категория;
- сложность от 1 до 3.

Основная база сверена с официальной книгой правил IIHF 2026/27. Часть карточек —
дополнительные хоккейные термины, которых нет в книге, но которые полезны болельщикам
и юным игрокам. У каждой карточки есть внутренний `bookRef` с правилом и страницей книги;
в интерфейсе он не показывается.

Из этой базы приложение автоматически собирает новые тесты на восемь вопросов.
Основные тесты проверяют значение русских терминов: термин → определение и описание
ситуации → термин. Английское название показывается после ответа и не влияет на
результат. Для проверки перевода существует отдельный режим «Хоккейный английский».

Перед тестом можно изучить случайную подборку из семи карточек. Словарь поддерживает
поиск и фильтрацию по восьми категориям.

## Полный сезон

Режим «Полный сезон» позволяет пройти все 106 учебных карточек:

- 8 матчей по 12 вопросов и финальный матч из 10 вопросов;
- каждая карточка появляется ровно один раз за сезон;
- результат сохраняется после каждого ответа;
- незавершённый матч можно продолжить позже;
- после финала показывается точность по каждой категории;
- до 12 ошибочных терминов можно повторить отдельным тестом.

Состояние сезона хранится в `localStorage` под ключом
`hockey-glossary-season-v1`.

Рядом доступен независимый `English Season` с теми же 106 карточками. Он проверяет
соответствие русских и английских названий, имеет собственные девять матчей,
статистику по категориям и работу над ошибками. Его прогресс хранится отдельно под
ключом `hockey-english-season-v1` и не влияет на основной сезон.

## Правила IIHF

Раздел «Правила» собирает материал по официальной книге IIHF 2026/27. Тесты
сгруппированы по разделам и отдельным правилам. Список разделов можно фильтровать
чипами.

Сейчас доступны разделы 01–10, 12 и Приложение I «Жесты судей»:

- полный учебный текст всех пунктов;
- 303 вопроса;
- тест по каждому правилу и общий тест раздела;
- изображения из книги, включая жесты судей.

Официальные определения из Приложения II уже входят в словарь проекта. Отдельного
раздела для них нет, чтобы не дублировать материал.

Женский хоккей, Приложение III «Снаряжение для хоккея», Приложение IV
«Справочные таблицы» и Приложение V «Технические требования» пока не входят
в учебный маршрут. Приложение VI «Инфографика» пока не добавлено.

## Проверка контента

```bash
node tools/validate-content.js
node tools/audit-content.js
```

`validate-content.js` проверяет структуру данных, вопросы и наличие картинок.
`audit-content.js` пишет эвристический отчёт `CONTENT_AUDIT.md`: перекосы, длинные
правильные ответы, повторяющиеся варианты и другие формальные признаки.

## Источники

- [IIHF Official Rule Book 2026/27 (EN)](https://blob.iihf.com/iihf-media/iihfmvc/media/downloads/rule%20book/2026-27_iihf_rule_book.pdf)
- [Официальная книга правил IIHF 2026/27 (RU)](https://fhr.ru/upload/iblock/a20/Ofitsialnya-Kniga-Pravil-IIKHF-2026_2027.pdf)

Определения и тексты вопросов пересказаны и упрощены для учебных целей, а не
скопированы дословно. При спорной игровой ситуации приоритет всегда имеет
актуальная официальная книга правил и регламент конкретного соревнования.
